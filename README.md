# 🎮 Quiz Royale

**Quiz Royale** is a fast, fun, and competitive quiz app designed to test your knowledge and challenge your friends. Built with Flutter and Firebase, it combines smooth UI, real-time updates, and engaging gameplay — all wrapped in a clean and modern design.

---

## 🚀 Features

✨ **Interactive Quiz Battles**
- Play exciting quizzes across multiple categories.
- Earn points for each correct answer.
- Compete for the top spot on the leaderboard!

👥 **Leaderboard**
- See where you rank among all players.
- Watch your score climb as you improve.

👤 **User Profiles**
- Create and personalize your profile.
- Update your username and password easily.

🔒 **Authentication**
- Secure login & registration using Firebase Authentication.
- Email verification and password management included.

📊 **Firebase Integration**
- Real-time database for storing scores and user data.
- Smooth syncing with no lag.

🖼️ **Clean UI**
- Modern, minimal, and responsive interface.
- Built with Flutter’s Material Design components.

## 📱 Screens Overview

- **Splash / About Screen** – App intro screen (auto hides after few seconds)
- **Login / Register** – Secure Firebase authentication
- **Home Screen** – Central hub for quiz navigation
- **Quiz Screen** – Timed and interactive question gameplay
- **Leaderboard** – Displays global ranking of players
- **Profile Screen** – Manage account info, update credentials, or delete account
